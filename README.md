# Desenv.app 🚀

Bem-vindo ao repositório do **Desenv.app**! Este projeto contém a estrutura básica de páginas web para autenticação e navegação inicial.

## 📁 Estrutura do Projeto

O projeto é composto pelos seguintes arquivos principais:

* **`home.html`**: A página inicial ou painel principal (dashboard) acessado após o acesso.
* **`login.html`**: A interface de login onde os usuários entram com suas credenciais.
* **`registro.html`**: A página de cadastro para novos usuários criarem suas contas.
